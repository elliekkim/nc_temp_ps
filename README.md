# nc_temp_ps
North Carolina Temperature, Preferentially Sampled

>This repository contains the code used to explore preferential sampling across the State of North Carolina.

This is the codebase for "Adjusting for Preferential Sampling in Citizen-Collected Climate Data" (Kim et al., 2026).

## Repository Organization

`/src/nctempps` contains source code for the models, dataloaders for real and synthetic data.

Available in the `requirements.txt` file.
